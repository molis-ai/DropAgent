# 动作列表改成纵向：按钮 + 说明

## 背景

动作区现在是两列图标+短名。看不出每个动作具体干什么。要纵向排开：前面是按钮，后面是一句说明。

## 范围

- Recipe 和「其他」改成单列。每行：左 120pt 纸面按钮（描边图标 + 短名），右一句 muted 说明。
- 点按钮才触发。说明不是大卡片。
- 禁用时按钮变淡，说明仍可读。
- 「其他」选中只亮按钮，不把整行做成色块。
- 不改 Recipe 调用链、确认页、轮盘。

## 说明文案

| 按钮 | 说明 |
|------|------|
| 总结 | 收成一篇短文，原件不动 |
| 抽取 | 抽出要点、待办或数据 |
| 翻译 | 译成指定语言，尽量留版式 |
| 脱敏 | 去掉联系方式、证件等敏感信息 |
| 转 MD | 转成可编辑的 Markdown |
| 整合 | 选几份，合成一份新稿 |
| 其他 | 写一句话，连同选中材料发给终端 |

## 验收

1. 预览空动作区是七行纵列，不是两列网格。
2. `--e2e` 仍能点 `recipe-summarize`。
3. Check 全绿。
