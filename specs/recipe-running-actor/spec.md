# 副本任务运行时写明是芯片那家 CLI

## 背景目标

点快捷动作后，确认区 / 运行中必须写明是当前芯片对应的 CLI 在任务副本里跑。禁止「芯片是 Grok、实际却是 Codex」。

本项被 `specs/recipe-follows-chip/spec.md` 收口：动作跟芯片走，不再永远绑 Codex。

## 当前行为与问题证据

旧文案：`Codex 在副本里跑，不是 Grok 终端。` 在 Recipe 已跟芯片之后会变成新的分裂。

## 范围

- `recipeActorLine`：有执行入口时写「\(芯片) 在任务副本里跑。」；没有则写该 CLI 没有无界面执行入口。
- 确认态、运行态、这两种页脚共用。
- 不改四条调用链。

## 非目标

- 解析 TUI、模拟按键。
- Developer ID。

## 验收

1. 预览确认、运行中、等授权：执行者与头上芯片同一家，出现「任务副本」。
2. 没有「不是 Grok 终端」这种对照句。
3. Check 全绿。
