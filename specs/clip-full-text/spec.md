# CLIP 标题和正文要能看全

## 背景与目标

粘贴进架子的 CLIP，标题和正文都被截断。人看不出刚贴进去的字。卡片、悬停、结果预览都应把标题和正文完整换行展示；过长的才滚动，不再先剪成 88 字或 900 字。

## 当前行为与问题证据

- 进货标题固定为「剪贴板」，正文被 `ItemPeek.cardText` 压成一行再截到 88 字，卡片 `lineLimit(2)`。
- 悬停把 `clip.txt` 当 Markdown，段落/标题没有垂直 `fixedSize`，一行截断；另有 900 字上限。
- 结果预览 `stagedTextView` 同样没有让正文撑开。

## 范围

- CLIP 标题用正文第一行（空则仍叫「剪贴板」）。
- 卡片：第一行当标题、其余当正文，保留换行。高度和其他文件卡一样，多出来的字在卡片上截断，悬停和结果预览看全文。
- 悬停和结果预览：全文换行；悬停过长仍靠现有滚动，不再 900 字截断。
- Markdown 渲染的标题/段落也要换行，避免 CLIP 悬停被当成 Markdown 后截成一行。

## 非目标

- 不改剪贴板历史行上的 40 字摘要。
- 不改进货、拖出、OCR。

## 验收标准

1. 粘贴「标题行\\n正文行」：架子标题是「标题行」，卡片能看到正文行；卡片高度和其他文件卡相同。
2. 单行 CLIP：标题是整句，不先截成 88 字。
3. Check：进货标题取第一行；`ItemPeek` 分出标题和正文。
4. `--e2e`：CLIP 标题是测试句，拖出 `clip.txt` 正文仍在。

## 验证命令

```bash
cd macos && swift run DropAgentCheck
DROPAGENT_ROOT=/tmp/dropagent-e2e-live macos/.build/debug/DropAgent --e2e
```
