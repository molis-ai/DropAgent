# 中间栏占满高度，运行中有转圈

## 目标

动作区现在内容顶在上头，下面空一截。让中间栏占满可用高度。执行中居中转圈，提示正在运行。各状态用图标和一点颜色区分。完成等级：功能可用。

## 范围

- 工作区（动作 / 预览）随中间栏高度撑开，短内容不再贴顶留下死空白。
- 运行中：居中转圈 +「正在运行」+ 当前事件；取消在下方。等待授权、失败用对应图标和色。
- 左列状态标签跟着用同一套色（运行、失败、已进终端、可拖出）。
- `prefers-reduced-motion`、`--preview`、`--e2e` 不转圈，用静止图标。
- 不改 Job / 调用链。颜色只用于状态，不是品牌强调色。

## 验收

1. 运行中：中间能看到转圈（或静止图标）和「正在运行」，取消仍可用。
2. 中间栏随窗口高度变高，运行态大致居中，不是贴在 tab 底下。
3. 失败 / 等待授权 / 已进终端 / 可拖出 有不同图标和色。
4. `cd macos && swift run DropAgentCheck`；`swift build --product DropAgent`。
