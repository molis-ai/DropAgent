# 设置：快捷键可改，并写清拖入读写场景

## 背景与目标

快捷键写死在 Carbon 注册和面板 footer 里，设置页看不到、改不了。人也不知道能拖什么、Agent 读什么、写到哪。设置里补上全部快捷键，以及和产品事实一致的使用说明。

## 当前行为

- 全局：`⌃⌥D` 开合面板，`⌃⌥W` 抓当前页。占用了只在 footer / 设置清单里提一句。
- 面板内：Esc 收起、⌘V 粘贴、⌘C 复制、↑↓ 选条、Delete 移除。不能改。
- 设置已有工作区、颜色、语言、Runtime，没有快捷键和场景说明。

## 范围

- 设置增加「快捷键」：全局两条可录制；面板内 Esc / 粘贴 / 复制 / 删除可录制；↑↓ 只展示。录制时点格子再按下组合。全局必须带至少一种修饰键。恢复默认。改完立刻重注册。
- 设置增加「能做什么」：拖入（图标 / 顶边 / 左列表 / 右 AI）、可接收类型、浏览器链接 vs ⌃⌥W 整页、拖出交什么货、读什么、写哪里、不覆盖原件。文案只陈述已有能力。
- `HotKeyCopy` / 设置清单标题跟当前键走。
- 不改四条调用链。

## 非目标

- 不为每一家 App 写插件说明。
- 不把 Recipe prompt 改成英文。

## 验收

1. 设置能看到并改开合面板、抓页快捷键；改完热键按新组合生效，旧组合失效。
2. 设置里有拖入、拖出、读、写说明，且与 `01` / `02` 一致。
3. Check 全绿；`--e2e` 打开设置能看到快捷键和说明区块。
