# 顶栏搜索、列头对齐、中间 Tag

## 目标

搜索放到顶栏正中，结果用下拉。左右列头同一套「输入 / 结果」。中间动作 / 终端 / 预览改成分开的 Tag。主操作实心，次要安静。

## 行为

- 顶栏：字标左，搜索中，终端芯片和窗口按钮右。满 2 字才下拉；点一行加入架子并清空；Esc 或点外面收起。+ 仍在左列头。
- 左列头与右列头同高、同样式。多选在「输入」右侧。
- 中间三个 Tag 间距约 10pt。选中浅底；不可用更淡。
- 「在副本中运行」用主按钮。Recipe 短名用 Tag，说明仍是旁边灰字。

## 验收

1. 搜索不在左列；`shelf-search` 在顶栏。
2. 左列有「输入」，右列「结果」，头高相同。
3. `swift build --product DropAgent`；`swift run DropAgentCheck`。
