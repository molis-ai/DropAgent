# 文件、内容、动作三层，像 PPT

## 背景与目标

外侧悬停预览会被屏幕切掉；整页「打开」又盖住文件和动作。改成：上面文件卡，中间看选中内容，下面动作栏。点卡不是弹出新层，是把内容放到中间。

## 当前行为与问题证据

点卡会盖住整个面板正文。用户要同时看到文件条、正文和动作。

## 范围

- 选中一份文件或结果时，在文件列表和动作栏之间出现内容台，展示可滚动正文或图。
- 换选中项：中间换成那一项。取消选中：中间收起。
- 多选时仍展示当前焦点那一份（选中列表第一项）。
- 不再从卡片悬停弹出外侧预览，也不再整页覆盖。
- 双击仍用系统打开。

## 非目标

- 不改 Recipe / OCR。
- 不把内容台做成独立窗口。

## 验收标准

1. 点 Markdown 或 CLIP：上面仍是文件卡，中间是全文，下面是动作栏。
2. 点另一张卡：中间换成新内容。
3. `--e2e`：选中后 `stagedItem` 有值；取消选中后为空。

## 验证命令

```bash
cd macos && swift build --product DropAgent
DROPAGENT_ROOT=/tmp/dropagent-e2e-live macos/.build/debug/DropAgent --e2e
```
