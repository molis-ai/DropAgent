# 动作栏可整理，快捷动作转圈出文件

## 背景与目标

文件下面的动作栏由用户自己排。自带动作可藏、可换序。加号添加快捷动作：指定文件类型和一句话，点了先出权限，再转圈，结果区出现 `原名-动作.md`。只有「其他」打开对话。

## 当前行为

动作栏顺序写死。没有用户快捷动作。「其他」是对话，总结等是 Job。

## 范围

- 栏最前：整理。可把动作从栏上拿掉、拖动手把换序（不要左右箭头）。拖动时当前条跟手，其他条实时让位。拿掉的是隐藏，设置里能加回来。
- 「其他」钉在加号前，不能藏。
- 栏最后：加号。名字、适用类型、Prompt。发给顶上当前芯片。
- 设置 → 动作：同一份清单。自带动作只能显隐和排序；快捷动作可改、可删。
- 快捷动作走 Job，不是 TUI。网络默认关。产出 `原文件名-动作名.md`（多选取第一份的名）。
- 选中类型不匹配则不出现该快捷动作。整理模式下仍列出已显示的动作，方便排序。
- 「文字提取」仍本机跑，可藏可排。不进轮盘。

## 非目标

- 不改自带 Recipe 的内部 Prompt。
- 不给每条动作锁死某一家芯片。
- 不开放任意 Shell。

## 验收

1. 默认栏仍有总结等；整理可藏脱敏，重启仍藏。
2. 加「抽付款日」（PDF）：选中 PDF 出现，选中图片不出现。确认后转圈，结果 `报价-抽付款日.md`，Prompt 在任务 prompt.txt，不打开对话。
3. 没芯片时快捷动作不能跑；「其他」有终端仍可发。
4. Check + `--e2e` 覆盖文件名、隐藏、快捷 Job。

## 验证

cd macos && swift run DropAgentCheck
cd macos && swift build --product DropAgent
DROPAGENT_ROOT=/tmp/dropagent-e2e-live macos/.build/debug/DropAgent --e2e
