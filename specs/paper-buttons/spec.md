# 可点的地方要看得出是按钮

> 2026-09-11：本项涉及的首次流程、文案和组件样式由 [UI 与引导优化](../ui-onboarding-refresh/spec.md) 更新；原有业务与权限边界保留。


## 背景与目标

面板里很多动作现在是裸字或裸图标，只有悬停才有反馈，休息态看不出能点。按钮要符合纸面风格：浅底、细线、圆角，不是系统灰钮，也不是大色块。

完成等级：功能可用。

## 范围

- 次要按钮休息态：浅纸片 + 细描边；悬停加深；按下再深并下移 1px。
- 图标按钮（设置、关闭、添加、粘贴、发送、叉）：同一套纸片，正方形。
- 主操作（在副本中运行、保存、发送）：实心强调色。
- 动作栏 Recipe、选项、多选、放到上面当材料、复制、终端、取消、设置里的拿掉/放回/编辑：都用这套，不再 `.plain` 裸点。
- 文件卡、目录树、内容台正文：仍是选择/阅读表面，不当成工具按钮。

## 非目标

- 不改 Recipe / 进货 / 编辑副本的行为。
- 不把文件卡做成按钮。

## 验收

1. 头栏设置 / 最小化 / 关闭、文件行 + 和粘贴、动作栏各项，休息态能看出是按钮。
2. 结果区「放到上面当材料」「复制」、确认「在副本中运行」看得出主次。
3. `swift build --product DropAgent` 与 `--e2e` 通过。
