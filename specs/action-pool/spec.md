# 设置里的动作池和栏上两栏

## 背景与目标

设置 → 动作现在是「栏上 / 已拿掉 / 快捷动作」三段。拿掉之后要滚到下面才找得到放回；新快捷动作一保存就进栏。人要一个池子：动作还在，栏上只是此刻拿出来用的。

完成等级：功能可用。

## 当前行为

- `actionOrder` 是栏上有哪些。拿掉就是从这里删掉。
- 设置里另有「已从栏上拿掉」和「快捷动作」。
- 保存快捷动作会 `append` 进 `actionOrder`，直接出现在动作栏。
- 设置里点添加会先关掉设置，去底下做表单。

## 范围

- 设置 → 动作改成左右两栏：左「动作池」，右「栏上」。
- 池子 = 预置动作里没上栏的 + 没上栏的快捷动作。栏上 = 现在的 `actionOrder`。
- 「其他」仍钉在动作栏加号前，不进这两列，拿不掉。
- 池子每项「放到栏上」；栏上每项「放回池子」。栏上可拖排序。
- 预置动作不能删。快捷动作可编辑；删除只影响这份快捷动作（栏上有也一并拿掉）。
- 添加快捷动作先入池，不自动上栏。设置里添加时不关设置，表单做在池子栏。动作栏「+」仍用底下表单；保存后提示已进池子，可「放到栏上」或去设置。
- 图片 / PDF 两份文字提取在池子里用全名分开。
- 动作栏整理里的叉仍是放回池子。

## 非目标

- 不互拖两栏。不多套栏方案。不删预置动作。不改 Recipe 执行。

## 验收

1. 设置动作页左右两栏。拿掉的预置动作在左边，点「放到栏上」回到右边和动作栏。
2. 新快捷动作保存后不在动作栏；在池子里。再放到栏上才出现。
3. 「其他」不出现在两栏里。
4. `swift build --product DropAgent` 与 `--e2e` 通过。
