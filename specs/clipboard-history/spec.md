# 剪贴板历史：粘贴按钮后面的十条旁路

## 背景与目标

文件行上的粘贴按钮现在直接把**当前**系统剪贴板加成一条。人常常刚复制过几段，想回头看一眼再决定用哪条。历史不能变成首页，也不能改掉 ⌘V 的快路径。

完成等级：功能可用。

## 当前行为

- 文件行粘贴按钮、对话浮窗粘贴、⌘V：都是 `pasteFromClipboard()`，只读当前剪贴板。
- 结果区「复制」/ ⌘C：把选中项写入系统剪贴板。
- 不记历史，关面板即无。
- 产品事实仍写「不是剪贴板管理器，没有历史列表当首页」。

## 范围

- 文件行上的粘贴按钮打开历史列表，不直接进货。
- 盯系统剪贴板；本 App 点复制写入系统剪贴板的，一并进入。
- 关面板、退出后再开：历史还在。默认 10 条，最新在前；满了丢掉最旧（FIFO）。相同内容不占新位，提到最前。
- 点文件行粘贴按钮：在按钮旁展开和面板同一套纸面的下拉菜单，最多 10 条。行上是摘要；圆点标出**此刻系统剪贴板那条**。
- 选择跟文件架一样：点选、再点取消；Command 点或多选模式加减。选中后可拖到架子或拖出。点击不直接进货。行上可删除。
- ⌘V、对话浮窗粘贴：仍直接贴当前。
- 结果区「复制」仍复制选中，从而进入历史。
- 密码管理器标成隐蔽 / 自动生成 / 临时的剪贴板：不记、不落盘。
- 字 / 图 / 链接落下 DropAgent 自己的副本；Finder 文件只记路径，没了就说「已经不在了」。

## 非目标

- 不当首页，不做独立剪贴板 App。
- 不改当前剪贴板（点历史一条不是「设为当前」）。
- 不把大文件再复制进历史目录。
- 不在对话浮窗的粘贴按钮上打开列表。

## 方案

- 内核 `DropAgentPasteboard.ClipHistoryStore`：10 条、去重、落盘、删、指纹。
- 数据在 `DROPAGENT_ROOT/Clipboard/`（`history.json` + 图片 blob）。不进 Inbox，不是架子 Item。
- App 轮询 `NSPasteboard.general.changeCount`；诊断启动（`--e2e` 等）不轮询，测试显式写入。
- 「放到架子」走现有进货链 `Ingest.admitPayload`。拖出走 Pasteboard writers。
- 贴按钮弹出独立层（位置跟系统菜单一样，不被文件卡裁切），纸面样式跟面板/搜索下拉一致。

## 验收

1. 点文件行粘贴：按钮旁展开面板风格下拉，最多 10 条；⌘V 仍把当前贴上架子，不打开菜单。
2. 在别的地方复制新内容（或本 App 点复制）：历史更新；相同内容提到最前，不新增。
3. 圆点在当前系统剪贴板那条上，和选中无关。点一条是选中，不进架子；Command 点可多选；选中后可拖。
4. 失效文件不能拖；行上可删除。
5. 删一条后不再出现；满 10 条再来新的，最旧的没了。
6. 隐蔽类型不入历史。关面板再开，历史还在。
7. `swift run DropAgentCheck` 与 `--e2e` 通过。

## 验证

```bash
cd macos && swift run DropAgentCheck
cd macos && swift build --product DropAgent
DROPAGENT_ROOT=/tmp/dropagent-e2e-live macos/.build/debug/DropAgent --e2e
```
