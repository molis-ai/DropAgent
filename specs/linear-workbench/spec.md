## 目标与现状证据

将 DropAgent 改成可真实试用的文件工作台。现有 `PanelRootView` 把材料横卡、`ContentStage`、`WorkPane`、结果横卡上下叠放；确认和运行会移除预览，对话又以独立纸面浮窗出现，导致窗口高度和操作位置不断变化。剪贴板只能从粘贴旁的下拉找。用户已选择左右布局、Linear 产品界面风格、底部常驻彩色指令及左侧默认可见的剪贴板历史，并要求轮盘同步升级。

完成等级：功能可用；交付原生可运行 App、关键主链路验证及明确的验证范围。未实际验证的外部 CLI、其他应用拖放目标不宣称验证通过。

## 场景与交互

1. 默认固定尺寸工作台，适配可用屏幕；状态变化不改变外窗高度。左侧窄目录，右侧大预览。材料、结果、剪贴板历史各自成组；结果有内容才出现，剪贴板默认可见并展开近期项，可以折叠。文件夹在左侧展开受现有 FolderListing 限制的目录，右侧看选中文件，不再嵌第二份目录。
2. 选择材料立即预览；多选仍针对一批材料，清楚显示数量。预览与执行对象须明确。单击同一目录对象保持预览，Command/多选继续选择集合；双击系统打开，拖出、隐藏与删除副本可用。
3. 常用指令在右侧底部始终成一排，不放进「全部指令」折叠菜单。默认动作和自定义动作配置保留；窄宽或自定义动作较多时允许横向滚动。当前不适用的动作禁用，不误用后台保留的材料选择。参数/确认/进度/失败在指令栏上方展开；预览始终保留。运行时禁止再跑同执行器任务，取消和失败重试可见。
4. 产出追加到左侧结果组。仅当仍在原任务材料上时自动预览结果，不能打断剪贴板、其他材料、草稿或对话。点「对照原文」按需展示目录/原文/结果三栏；多材料结果可选原文，缺失原文有明确不可用状态。窄窗口保留可读预览。对照原文只读，结果仍可编辑副本、复制、拖出或用作材料。
5. 剪贴板历史点选只预览，不写系统剪贴板、不上架、不运行。当前记录标「当前」。可复制（切为当前）、拖出、删除记录、明确加入材料；加入复用 Ingest 并保留 URL 抓取规则。文件缺失/图片丢失有明确状态；多条加入时成功项入架，失败原因仍可见，不伪装全部成功。复用现有 10 条历史、敏感类型过滤和外部复制文件自动上架规则。
6. 对话/终端统一在右侧下方展开；收起、预览切换和设置切换不销毁已有 PTY。保留会话投递边界和恢复文案。
7. 主界面和轮盘采用 Linear 产品界面式的中性分层背景、紧凑行、小图标、轻分隔、连续内容面。浅深主题都可读；功能图标使用固定蓝、灰紫、麦色、陶土色组，文字保持中性；禁用回灰，不使用绿色。轮盘六瓣、中心空区、动作语义、拖放规则保持，Markdown 使用「转 MD / To MD」短标签，升级悬停/选中反馈与边界层次，尊重减少动态效果。

## 模块与数据边界

- `AppSession`：新增剪贴板预览焦点、原文对照状态和文件夹预览选择；选择/复制/删除/键盘/动作门禁必须识别新焦点。历史仍不是 Shelf Item。
- `PanelRootView`、目录视图、预览/内容视图、指令及确认视图、`AIPane`：布局和展示。
- `Palette`、按钮/文件图标、`EdgeDropView` 及关联轮盘绘制：视觉和反馈，复用既有动作映射及几何算法。

- 更新 `DESIGN.md`、产品/原型/架构事实及 README 相关说明；现有未提交工作完整保留，不做无关重构。
