# 左目录：目录名缩进与行尾按钮

状态：已实现。完成等级 3（功能可用）。唯一需求书。依据本会话「剪贴板和材料区文件带缩进、行尾按钮不要右键」及补充「材料变成目录名、搜索框拉宽、右边是加号」。

## 背景目标

Linear 工作台改版后，材料组仍是「标题 + 搜索图标 + 加号」横条，文件与组标题齐平；复制 / 加入材料 / 隐藏 / 删除靠右键菜单。要改成和剪贴板一样的目录名，文件缩进在目录下，行尾动作用按钮点。

## 当前行为与问题证据

- `WorkbenchSidebar` 材料组把头上的搜索、添加、更多和「材料」标题绑在一起；剪贴板才是 chevron + 名称 + 数量。
- `WorkbenchFileRow` 与剪贴板行用 `.contextMenu`；材料没有行尾按钮。
- 搜索靠 `shelf-search-toggle` 展开，默认不占宽。

## 范围与非目标

范围：左侧目录顶栏、材料 / 结果 / 剪贴板组头、文件行缩进与行尾按钮。选择、拖出、双击打开、⌘V、加入材料走 Ingest、隐藏 / 删除语义、剪贴板预览无副作用均不变。

非目标：不改右侧预览与底部指令；不改内核契约；不把剪贴板文件清单再展开成第二层树；不恢复旧文件卡。

## 使用场景

打开工作台，顶上就能搜本机文件，加号在搜索框右边。材料、生成结果、剪贴板都是可折叠目录名。文件相对目录缩进一级。悬停或选中一行，尾部出现复制、加入材料（仅剪贴板）、隐藏、删除，不再右键。

## 方案与关键决策

1. 搜索框固定在目录顶部并拉宽，右侧保留 + 与「…」（粘贴、多选）。不再用放大镜开关。字段不自动抢焦点。
2. 材料、结果、剪贴板同一套目录头：chevron、图标、名称、数量。默认展开；点组头折叠。选中该组或新进货时自动展开，避免人看不见刚加入的文件。
3. 文件相对目录缩进一级；文件夹选中后子项再缩一层，沿用现有 `FolderListing`。
4. 行尾按钮，悬停或选中可见：材料 / 结果为复制、隐藏、删除；剪贴板为复制、加入材料、删除。运行中或剪贴板文件缺失时禁用对应动作。去掉这些行的 `contextMenu`。⌫ 仍是隐藏材料 / 结果、删除剪贴板记录。双击仍系统打开。

## 输入输出与依赖

输入：现有 Shelf Item、ResultRecord、ClipRecord。输出：同一套进货 / 复制 / 隐藏 / 删除。依赖 `AppSession` 现有方法，不新增业务包 API。
