# 文件在上、结果在下、对话浮窗

## 背景与目标

菜单栏面板从左中右三栏改成：上面文件、选中才出动作、下面结果区、点「其他」才出独立对话浮窗。设计效果图在 `.impeccable/mocks/layout-chat.html`。

完成等级：功能可用。原型已改完。原生壳见 `work-items/native-panel/spec.md`。

## 当前行为

三栏：左输入、中工作（动作 / 终端 / 预览）、右结果。动作常驻中间。结果常驻右侧。

## 范围

- 设计原型布局与动线（已完成）。
- 原生 `macos/App` 面板改成同一套 IA，见 `work-items/native-panel/spec.md`。
- 更新 `02-prototype-design.md`、`PRODUCT.md`、`DESIGN.md`、壳文档。
- 保留现有能力：拖入拖出、轮盘、多选、Recipe 确认与隔离四行、运行/取消、终端发送、预览、复制、隐藏/移除、设置、就绪、无终端 / 仅终端。

## 非目标

- 不改 `macos/Packages/` 内核业务规则。
- 不删 Recipe、终端、预览、拖出、隔离确认。
- 不覆盖用户原件。

## 方案

| 原位置 | 新位置 |
|--------|--------|
| 左列输入 | 面板上方横向文件卡 |
| 中列 Recipe | 选中文件后出现的动作栏 |
| 「其他」底栏 | 面板下方独立浮窗（中间露出桌面） |
| 中列终端 | 同一浮窗里看会话 |
| 中列预览 | 悬停预览；点结果也可在浮窗看正文 |
| 右列结果 | 文件下方「结果区」，无结果则不出现 |
| 拖回左列 | 选中结果后「放到上面当材料」（复制） |
| 确认 / 运行中 | 动作栏下方的确认条，不打开浮窗 |
| 栏：工作 / 结果 | 结果区无结果则不出现；动作不再是常驻栏 |

面板默认约 1040 宽。文件与结果各一行，不折成左右栏。

文案：上面「文件」，下面「结果区」，按钮「放到上面当材料」。

## 验收

1. 未选文件：只有文件行，无动作栏、无浮窗、无结果区。
2. 选中文件：动作栏出现。点总结仍先确认（选项 + 读/写/网络/隔离），确认后结果出现在结果区。
3. 点「其他」：浮窗出现在文件架下方，不与面板连成一块；可发给终端。圆角、阴影、「对话」分区条和输入条与文件架同一套，不是更圆的胶囊条。
4. 选中结果：出现「放到上面当材料」，复制到文件行，结果区仍保留。
5. 悬停文件或结果：预览弹出。
6. 轮盘、拖到桌面、⌘V、设置、就绪、无终端禁用动作，场景按钮仍可用。
7. `01-requirements.md` 的业务规则不变。
