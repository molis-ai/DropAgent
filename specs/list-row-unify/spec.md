# 左右列表同一套行样式

## 目标

输入列行样式跟结果列一致：小圆角条、标签 + 标题 + 一行说明、右侧时间，悬停换成隐藏/删除。

## 范围

改 `ItemRowView` 和输入列列表容器。多选勾、运行中脉冲、运行中不能隐藏/删除仍保留。不改进货、Job、结果列行为。

## 样式

以 `ResultRowView` 为准：字 12 / 10，内边距 8×6，行距 2，选中 `panelPress` 圆角 6。不要 56 高、不要底部分割线、不要左边蓝条、不要状态胶囊。

## 验收

1. 输入行与结果行同一套排版和选中态。
2. 运行中仍无隐藏/删除；多选仍有行前圆圈。
3. `swift build --product DropAgent`；`swift run DropAgentCheck`。
