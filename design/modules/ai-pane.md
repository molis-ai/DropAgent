# 模块：AI Pane（App 内 UI，不是独立内核包）

布局以 `specs/linear-workbench/spec.md` 为准。`WorkbenchDetail` 装配右侧预览、任务确认和进度、常驻指令、嵌入式 `AIPane`；业务规则来自 Job / TUI / Agent。

- `RecipeChooser` 在右下常驻，六个 CLI 动作与本机文字提取沿用能力判断，整理与自定义动作保留。非材料焦点、运行中或当前材料待确认时不允许再次点动作。
- `WorkPane` 在指令上方显示确认、运行、失败和重试。确认范围、网络与隔离事实如实显示；确认才调用 Job，预览一直在。
- `AIPane` 在右下按需展开，包含 PTY、输入、发送和终端边界说明；收起或设置切换不销毁已有终端实例。发送选中结果时只投递产出文件，不把旧材料标成 sent。剪贴板焦点不能直接发送。
- 目录点材料看副本，点结果看产出，点剪贴板只读预览。结果可复制、拖出或用作材料；原文对照只读，结果仍可编辑副本。
- 对话输入是发给 TUI 的话，不是 Recipe 的隐藏 Prompt。对话区 drop 走 Ingest（不抓页）再 TUI.send；材料区 drop 只进货。
- 不自行发现 Agent，不解析终端画面，不模拟按键，也不为布局增加内核调用链。
