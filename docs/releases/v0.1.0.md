把 PDF、截图、网页先放到菜单栏，需要时在副本上处理，再把新文件拖走。

**DropAgent v0.1.0 是第一个公开版本。** 它把文件暂存、本机文字提取和你已有的终端 Agent 放到同一个工作流里：放入材料 → 选择动作 → 确认 → 拿走结果。

![DropAgent 首次体验](https://raw.githubusercontent.com/molis-ai/DropAgent/v0.1.0/docs/readme/onboard.png)

## 核心功能

- **随手放，随时取。** 暂存文件、文件夹、图片、文本和链接；支持拖入、粘贴、搜索本机文件和剪贴板历史。点选材料即可预览，文本副本可以直接编辑。
- **不装 Agent，也能完成第一件事。** 图片文字识别在本机生成 `ocr.md`；PDF 的可选中文字提取为 `pdf.md`。无需联网或模型账号，内置示例 PDF 可以直接试用。
- **让已有 Agent 处理零散材料。** 提供总结、提取信息、翻译、脱敏、转 Markdown 和多文件整合；支持自定义快捷动作。总结、翻译等 AI 动作需要本机安装并配置可用的 CLI Agent。
- **处理前看清范围。** 确认页展示读取的副本、输出位置、网络与隔离能力。快捷动作在任务目录中生成新文件，DropAgent 不自动覆盖原文件。
- **结果拿得走，也能继续用。** 结果可以预览、复制、拖到 Finder 或其他应用，并可重新用作材料。支持在内嵌终端中继续对话。
- **贴合 macOS 的入口。** 菜单栏、可选拖拽轮盘、当前网页抓取、Finder 选中文件导入、可配置快捷键、深浅主题和中英文界面。面板可以拖动，收起重开会记住位置。

## 下载与安装

下载下方附件 **`DropAgent-v0.1.0-macos-arm64.zip`**，解压后将 `DropAgent.app` 拖进「应用程序」，双击打开，再点击菜单栏图标。

- **系统：** macOS 14 或更新版本。
- **芯片：** Apple Silicon（M 系列）；本次不提供 Intel 安装包。
- **无需开发工具：** 安装包不需要 Xcode 或 Swift。
- **签名状态：** adhoc 签名，尚未经过 Apple 公证。若系统拦截，确认来自本仓库后，按 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，在尝试打开后前往「系统设置 → 隐私与安全性 → 仍要打开」。

`SHA256SUMS.txt` 可用于检查下载文件的完整性。

## 第一次试用

1. 点击 **「试用示例 PDF」**。
2. 选择 **「提取文字」**，确认后点击 **「开始提取」**。
3. 在结果区打开 `pdf.md`，复制内容或把结果文件拖到桌面。

这条路径不需要 Agent、辅助功能或屏幕录制权限。浏览器抓取、Finder 导入按需授权；拒绝相关权限仍可使用文件暂存和本机文字提取。

## 使用边界

- 扫描件 PDF 不等同于已完成 OCR；没有可选中文字时会说明无法直接提取。
- DropAgent 不自带模型，也不直接接云端模型 API。你选择的终端 Agent 仍可能使用它配置的云服务，并产生对应费用。
- 隔离能力由具体 CLI 决定。确认页会区分 Workspace Sandbox、Safe Copy 或未确认；Safe Copy 不代表整个宿主进程都处于严格沙箱内。内嵌终端对话会单独说明处理范围。
- 抓取登录墙、动态页面的正文可能不完整。网页抓取和真实 Agent 行为还受系统权限、网络及本机配置影响。
