## 主要变化

- 浅纸底、灰绿侧栏、深绿主操作，配套深色主题；清理装饰性圆点和过小的标题。
- 文件名独占清楚的行，类型、时间和状态分层；隐藏／删除只在悬停或选中时露出，透明控件不拦点击。
- 动作整行可点，说明、选项和下一步更容易理解；粘贴入口固定在输入栏底部。
- 搜索参与顶栏布局，收窄窗口后不再覆盖 Agent 和栏开关。
- 原生按钮按压反馈、克制的展开／入库过渡，尊重减少动态效果设置；保留终端实例，切换页签不销毁会话。
- 失败且没有产出时明确说明，并提供返回原材料重试，避免显示无效复制、拖出或发送入口。

## 修复的使用问题

| 问题 | 处理 |
| --- | --- |
| 点击结果后，方向键被搜索框截住或跳回输入 | 行选择交还窗口焦点；结果导航留在结果列表 |
| 从结果视图加入新材料，仍发送旧结果 | 成功入库切回输入并清理旧错误 |
| 有输入任务运行时，已有结果也被误判不能发送 | 按当前发送对象判断可用状态 |
| 批量准备副本中途失败，已有材料卡在运行中 | 准备与执行统一恢复；限制同一执行器并发启动 |
| 取消后晚到的结果仍可能登记为成功 | 落结果前检查取消状态 |
| 无终端实例的旧“已发送”材料进入空终端页 | 返回可操作的工作视图 |
| CLI 输出量大时可能互相等待，界面一直运行 | 同时持续读取 stdout / stderr；补齐启动失败的资源清理 |
| CLI 失败但有 stdout，被误当作成功 | 非零退出明确失败 |
| Grok 的工具调用说明进入交付文稿 | 读取正式 streaming JSON 的最终 result，保留 Markdown；过程事件单独反馈 |
| 不同站点的相同 URL 路径被误去重 | 按完整 URL 判断 |
| 首次构建被 Swift 6 跨 actor 检查阻断 | 修正拖放提供者的主 actor 桥接 |
| 打开“其他”后的焦点与输入同步不稳定 | 延后到视图挂载后请求焦点；不覆盖正在组合的输入文本 |
