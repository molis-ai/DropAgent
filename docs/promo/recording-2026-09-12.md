# DropAgent 推广演示 · 2026-09-12

用户要求：直接用本机 Recordly 录成视频，使用新 macOS 桌面，介绍核心功能与轮盘、拖拽、剪贴板、快捷动作等交互；后续特别要求展示“把暂存区的材料拖到其他地方”。中文横屏，目标约 90–100 秒；使用当前本地开发版本，画面注明“开发预览”。不自动发布。

## 演示判断

产品演示领衔，用一个真实完成的文件任务作为证据。面向手头经常有 PDF、截图、会议记录，已经在用终端 Agent 的 Mac 用户。开头直接给轮盘，最后给能拖走的新文件。功能目录式逐项念配置会遮住完整结果，因此不采用；教程细节留给项目 README。

- 注意力：拖动一份文件，鼠标旁出现轮盘。
- 留存：跟着一份会议纪要，看它变成能带走的文字和待办。
- 信任：原生应用实际操作、真实生成的结果；等待过程如有压缩会注明。样例数据为虚构。
- 行动：到 `github.com/molis-ai/DropAgent` 看源码和下载安装说明。

## 录制与剪辑

- 使用用户已创建的新 macOS 桌面。Recordly 1.4.0 的主屏幕来源，包含菜单栏、轮盘和跨窗口拖拽；隐藏录制 HUD，关闭麦克风/摄像头，后期配中文讲解字幕。
- 准备独立演示数据目录与虚构会议材料。只通过真实 UI 操作完成演示；不使用 `--preview` 里的模拟运行状态，不伪造 CLI 产出。
- 镜头采用固定全景加关键交互局部放大；文字/文件名清楚优先。配色沿用当前暖纸白、雾蓝、炭灰，无绿色。
- 截掉准备、误操作和工具等待；保留足够时间让观众看清鼠标落点、确认页和结果。AI 等待加速时显式标注。
- 成片目标 1920×1080、30fps、H.264 MP4；字幕与项目文件/原始录制保存在本地交付包。

## 事实边界

- “快捷动作”是 DropAgent 的“名称＋适用材料类型＋一句话要求”，不是 Apple「快捷指令」集成。
- 系统快捷键另列：默认 ⌃⌥D 开关面板、⌃⌥W 抓当前网页、⌃⌥A 加入前台选中文件；录制以前以演示实例设置为准。
- 图片 OCR 用本机 Vision，PDF 提取针对可选中文字；扫描件 PDF 不宣传为已支持 OCR。
- CLI 动作需要本机可用且已配置的 Agent；不说“所有功能完全离线”。对话权限不等同于副本沙箱。
- 当前源码包含 v0.1.0 发布之后的新配色、Runtime 和剪贴板改进。成片不把本地开发行为误标为 v0.1.0 下载包已具备。
